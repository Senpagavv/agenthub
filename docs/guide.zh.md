# AgentHub 使用说明

这个命令行工具适合手里有一批文字任务、想比较模型结果的人。先做一遍，再挑需要复核的条目交给另一个模型。工具按相同的题目编号对照标准答案，也把复核成本算进去。

## 先试四条样本

安装 Python 3.10 或以上版本，在仓库根目录运行 `python examples/demo.py`。无需账号、密钥或联网。例题问文字有没有明确提到火车晚点。首轮把一条巴士晚点也算了进去，四条中答对三条。复核只处理这一个编号，最后四条全对。示例费用是演示数字。

## 使用自己的数据

1. 准备 JSONL，每行有唯一的 `id` 和 `text`。另存一份含相同编号和 `label` 的人工参考答案。可以对照 examples 目录。
2. 要实时调用 DeepSeek 或 TypeSafe Jev，在自己的终端设置对应的环境变量。先用 `--limit 4 --workers 1` 试一小批，检查当前模型名称与单价。
3. 用 `batch` 做生成或分类，或用 `jbatch` 做结构化判断。通过 `sample` 查看输出，再运行 `eval` 对照标准答案。
4. 低置信度或人工挑中的案例可单独交给第二个模型。用 `eval --fallback` 按原编号合并，比较正确率及每条样本的成本。

默认输出目录是 `runs/`。调用记录可能包含原始文字和模型回答，适合保存在自己的设备。可执行命令、字段与参数见[主说明](../README.md)。
